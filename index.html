Data scope

The dashboard uses a bundled 2023–2024 public archive; the four original ML/strategy experiments use the 2024 Dutch GP snapshot. Afterhours uses existing checksummed replay observations matched to official best race laps. The advertised full telemetry corpus is not loaded.

Honest boundary

The hosted showcase labels its backend Local / SQLite. Elastic and Hopsworks controls are disabled here; the separate workflow slide describes an integration architecture, not a live connection. GitHub Pages is a static overview.
